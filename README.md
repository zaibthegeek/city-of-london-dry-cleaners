# City of London Dry Cleaners

Website for City of London Dry Cleaners, the dry cleaning, shirt service and laundry business
operating from Canary Wharf and London Bridge since 1994.

Static site, no framework, no client-side rendering. Ten pages generated at build time from a
single content file.

## Stack

- Plain HTML, CSS and vanilla JS, generated by a small Node build script
- No dependencies, no bundler, no runtime framework
- Typography: Cormorant Garamond and Jost via Google Fonts
- Deployed on Vercel as static output

## Local development

```bash
npm run dev      # build, then serve dist/ on http://localhost:4321
npm run build    # build into dist/ only
```

Node 18 or newer.

## Project structure

```
src/data.js        All site content: services, prices, addresses, phone numbers
src/templates.js   Layout, header, footer and shared components
build.js           Page bodies and the build entry point
static/            Copied verbatim into dist/ (css, js, img, favicon)
dist/              Build output, not committed
```

## Editing content

Everything a client would want to change lives in `src/data.js`:

- `services` - the seven service pages, their copy, bullets and images
- `priceGroups` - the full published price list, grouped and ordered
- `locations` - the two branches, addresses, phone numbers and map links
- `headOffice` - Timpson Ltd head office details
- `credentials`, `process`, `corporate` - the home page supporting sections

Adding a service to the `services` array automatically creates its page, adds it to the header
dropdown, the mobile drawer, the footer and the sitemap. No other file needs touching.

Prices are stored as `[name, amount, isFrom]`. Set `isFrom` to `true` to render the "from" prefix.

`/suede-leather-cleaning` `/specialist-cleaning` `/tailoring-repairs-alterations`

The URL structure matches the previous WordPress site exactly, so existing inbound links and
search rankings carry over without redirects.

## The enquiry form

The contact form validates in the browser, then hands the completed enquiry to the visitor's
mail client addressed to `info@cityoflondondrycleaners.co.uk`. It includes a honeypot field
for spam.

This keeps the site fully static with nothing to host or maintain. To capture submissions
server side instead, point the form at an endpoint (Formspree, or a Vercel serverless
function) in `static/js/site.js`, replacing the `mailto:` handoff in the submit handler.

## Accessibility and SEO

- Skip link, single `h1` per page, labelled form controls, visible focus states
- `prefers-reduced-motion` respected for all animation
- Schema.org `Organization` plus a `DryCleaningOrLaundry` entry per branch
- Canonical URLs, Open Graph tags, generated `sitemap.xml` and `robots.txt`

## Notes on content

All copy, prices, addresses and phone numbers are taken from the client's existing site.
Obvious typographic and grammatical errors in the original copy were corrected; no facts,
prices or claims were changed or invented. Opening hours are not published anywhere on the
current site, so they are deliberately omitted rather than guessed.
